# Bot 插件安全边界

| 入口                    | 身份来源                             | 归属与授权                                               | 拒绝行为                                                     |
| ----------------------- | ------------------------------------ | -------------------------------------------------------- | ------------------------------------------------------------ |
| REST / Gateway          | 本地 Bot Token；服务端验证哈希和版本 | 当前 application、公会、可见频道、DM 参与者              | 拒绝跨来源 Token 发送、非法响应、撤销会话；致命关闭不重连    |
| MESSAGE_CREATE          | 已鉴权 Gateway 中的作者 ID           | 本公会可见频道；发送者 allowFrom；非自身/默认非 Bot      | 本地解密校验失败、明文降级、未触发时不派发                   |
| Interaction             | 服务端 command/application/caller ID | 已注册命令、参数类型和密文签名上下文                     | 不执行其他应用命令；私密接收人只含 Bot 与调用者设备          |
| OpenClaw native command | 上述 caller ID；主机 command-auth    | 主机所有者规则和当前注册代际                             | 普通 allowFrom 不授予 owner；不复用共享频道会话保存私密参数  |
| Outbound / 主动 DM      | 已解析账户、已持久化本地设备         | 每次实际写入由服务端重查频道/参与者/屏蔽/公会资格        | 设备不匹配或撤销拒绝；私密附件不扩大为公开附件               |
| 附件                    | 同源签名授权，OpenClaw 媒体读取策略  | 服务端频道授权与主机媒体目录/SSRF 限制                   | 拒绝重定向、大小/MIME 不符、非同源地址；本地路径经主机 guard |
| 本地状态                | OpenClaw 状态根和合法账户 ID         | 应用 ID 绑定、符号链接检查、目录 0700/文件 0600（POSIX） | 拒绝损坏/跨应用/越界状态；Windows 目录继承用户 ACL           |

排队事件总量有上限；配置变化、权限收回、断线与撤销会取消进行中及排队任务。处理账本只保存事件 ID 和过期时间。插件不将正文、指令参数或 Token 写入自己的日志/账本；OpenClaw 自身的会话数据遵循其本地状态策略。

本地测试与真实 Gateway 冒烟均使用临时目录和隔离数据库，不操作业务数据库。
